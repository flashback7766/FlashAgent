# Execution Loop

1. Прочитать веху в ROADMAP.md + срезы затронутого кода.
2. Минимальный набор правок. Скоуп = веха, ничего больше.
3. `cargo test --workspace && cargo clippy --workspace -- -D warnings` (+ golden для UI).
4. Провал → диагноз из вывода компилятора, максимум 2 точечных попытки на ошибку, дальше — стоп и эскалация владельцу с точным выводом.
5. Запись в `.audit/` со структурой из AGENTS.md. Статус вехи в ROADMAP.md обновить.
6. Handoff владельцу: что сделано, чем проверено, что открыто.
