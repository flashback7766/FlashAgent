**Changes Made:**
1. **Native MCP JSON-RPC 2.0 Stdio Client**:
   - Built a lightweight, zero-external-dependency native MCP client (`flashagent-tools::mcp::client`) using `tokio::process::Command`, async buffered streams, and correlation ID response matching via oneshot channels.
   - Handshake compliance with MCP 2024-11-05 specification: `initialize` with `clientInfo` and capabilities, followed by `notifications/initialized`, and tool discovery (`tools/list`).
   - Diagnostic ring-buffer for `stderr` capture: preserves the last 100 lines of child process errors to present exact failure causes in TUI error cards.
2. **MCP Configuration Manager**:
   - Multi-tier configuration discovery (`flashagent-tools::mcp::config`): searches project `.mcp.json` / `mcp.json` and user global `~/.flashagent/mcp.json`.
   - Dynamic environment variable interpolation (`${VAR}` and `$VAR`).
   - Granular read-only declarations (`read_only: bool` on server level, or `read_only_tools: Vec<String>`).
   - Project config scaffolding helper (`save_server_to_project`) for one-click installation from the marketplace.
3. **Curated & Verifiable Marketplace Registry**:
   - Built curated catalog (`flashagent-tools::mcp::marketplace`) of vetted standard extensions:
     - SQLite Database (`mcp-server-sqlite` via `uvx`)
     - GitHub Integration (`@modelcontextprotocol/server-github` via `npx -y`)
     - PostgreSQL Database (`@modelcontextprotocol/server-postgres` via `npx -y`)
     - Local Filesystem (`@modelcontextprotocol/server-filesystem` via `npx -y`)
     - Web Content Fetcher (`mcp-server-fetch` via `uvx`)
     - Brave Web Search (`@modelcontextprotocol/server-brave-search` via `npx -y`)
     - Docker Containers (`mcp-server-docker` via `uvx`)
     - Puppeteer Browser (`@modelcontextprotocol/server-puppeteer` via `npx -y`)
     - Git Repository (`mcp-server-git` via `uvx`)
     - Knowledge Graph Memory (`@modelcontextprotocol/server-memory` via `npx -y`)
4. **ApprovalGate & Security Layer Enforcement**:
   - Strictly enforced PHILOSOPHY.md §5 and .agents/skills/mcp.md: non-read-only MCP tools are categorized as `Category::Mcp`, requiring interactive confirmation with full JSON arguments preview in `Manual` and `AcceptEdits` permission modes.
   - External mutating tools are strictly denied in `Planning` mode.
   - Read-only tools (configured read-only or matching standard inspect/query actions) are categorized as `Category::Read` and executed seamlessly.
5. **TUI Slash Commands & Rich Visual Cards**:
   - `/mcp` & `/mcp help`: interactive overview card showing configured servers, status, total tools, and command list.
   - `/mcp list`: formatted boxed card displaying server connection states, latency, tool counts, and tool names preview.
   - `/mcp market`: categorized catalog browser with install syntax (`/mcp add <id>`).
   - `/mcp test <server>`: ping handshake latency measurement, tools list inspection, and server version display.
   - `/mcp add <id>`: scaffolds `.mcp.json` in the current project and launches the server in the background.
   - `/mcp reload`: terminates stale child processes, reloads configuration files, and restarts enabled servers.
6. **Version Bump to b200**:
   - Updated release versioning to `b200` across `README.md`, `packaging/build-all.sh`, and `packaging/arch/PKGBUILD`.
